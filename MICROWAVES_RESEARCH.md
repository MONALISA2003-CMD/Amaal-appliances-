## Implementation rule
Research exact models through OEM sources first, then cross-check Uganda local price/availability using credible retailers. Hisense was intentionally excluded from this expansion. No model number is invented.

## Researched but not implemented
- Several additional budget models were found, including Midea MM720C2GX-B, Midea EG8P022MX-S and various Saachi/Global Star models. They were held back from this implementation batch where a clean exact-model image could not be confirmed to the same standard.

## Image rule
No watermarked images, seller phone numbers, screenshots, promotional overlays, wrong models or similar-model substitutions are permitted. Full-product presentation uses `object-fit: contain` on catalogue cards and product-detail media.
